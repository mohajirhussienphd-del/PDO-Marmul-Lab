Westgard Multi-Rule Reference (as applied by this tool)

1-3s — One control observation exceeds ±3SD. Rejects the run (random error).

2-2s — Two consecutive observations exceed ±2SD in the same direction, either (a) both QC levels within the same run, or (b) the same level on two consecutive testing days. Rejects the run (systematic error).

R-4s — The range between two control levels within the same run exceeds 4SD (e.g., one level +2SD and the other −2SD). Rejects the run (random error).

4-1s — Four consecutive control observations (same level, across the last 4 testing days) exceed ±1SD in the same direction. Rejects the run (systematic error/trend).

10x — Ten consecutive control observations (same level, across the last 10 testing days) fall on the same side of the mean. Rejects the run (systematic bias).

This tool evaluates all five rules automatically after every entry, using the values entered in each analyzer's QC Target Settings panel. A row is flagged "In Control = N" if any rule fires; the specific rule(s) triggered are listed in the Westgard Flag column.

Backup & Restore

Why this matters: everything you enter (QC results, target Mean/SD, reagent stock edits, reorder list) is saved in this browser only. Clearing your browser's history/cookies/site data, switching computers, or using a different browser will lose it — because it was never saved anywhere else. Downloading a backup file protects against that.

Recommended: download a backup file at the end of each day or week, and save it somewhere outside the browser (e.g., a folder on the PC, a USB drive, or email it to yourself). To restore, open this page in any browser and use "Restore From Backup File" — it will reload the page with your data back in place.
